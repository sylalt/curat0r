# Curator

Curator is a small, static portfolio for collecting the images, music, objects and ideas that shape a personal point of view.

## Site structure

- `index.html` contains the five sections and their copy.
- `style.css` contains the responsive visual system.
- `assets/` contains the images used on the page.

The site has no JavaScript application, account, browser database, journal, inbox, save controls, or backup integration. Its navigation uses regular in-page links. To add or change content, edit `index.html` and add image files under `assets/`.

The supplied moodboard is presented as the first Visual Archive feature. The six @showcasejournals guide screenshots are no longer used by the portfolio.

## Publish

GitHub Pages serves the static files from the repository. No build step or package installation is required.
